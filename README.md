# IZUMI OKAMURA | PORTFOLIO

Web制作・デザインの学習を通して制作した、個人ポートフォリオサイトです。
「和」の意匠(生成り・墨・紅・藍)をベースに、余白と縦組みタイポグラフィを活かしたデザインを目指しました。

🔗 **Live Site**: https://izumi-yk24.github.io/portforio/

---

## 📌 サイト概要

TOPページを起点に、WORK / SKILL / ABOUT の各ページへ遷移するシンプルな構成のポートフォリオサイトです。
TOPページはスクロールなしの1画面デザインとし、横に重なったカードから各ページへ遷移できるUIを採用しました。

---

## 🎨 デザインコンセプト

- **カラー**: 生成り(クリーム)を基調に、墨・紅・藍・黄などの和色をアクセントとして使用
- **フォント**: 見出し・本文ともに Zen Kaku Gothic New を使用し、フォントウェイトの強弱で階層を表現
- **レイアウト**: CSS Grid / Flexbox を用いた余白重視のレイアウト。装飾は最小限に抑え、コンテンツが引き立つ設計を意識

---

## 🛠 使用技術

- HTML5 / CSS3(素のCSSのみ、フレームワーク不使用)
- CSS Custom Properties によるカラートークン管理
- レスポンシブ対応(768px / 440px ブレイクポイント)
- Google Fonts(Zen Kaku Gothic New)

---

## 💡 工夫した点

- CSS Grid を用いた作品一覧のレイアウトでは、セクションごとに列数を変えられるようmodifierクラスを設計
- TOPページのカードUIはホバー時にアニメーションで展開し、視覚的な楽しさを演出
- レスポンシブ対応では、要素の優先度に応じて表示/非表示を切り替え、狭い画面でも情報が破綻しないよう調整
